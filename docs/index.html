Install in three steps

  1. Open the latest release and download the APK.
  2. Open the file. If Android asks, allow Install unknown apps for your browser.
  3. Open Sandrix Studio IDE, allow storage access, and tap New project.

Questions

Is it free?

Yes. Download and use the app at no cost.

Why does Android warn me when I install?

The app is not from the Play Store, so Android shows a standard warning for any APK you download yourself. Choose Install anyway.

Does my code leave my phone?

No. Projects are built on your device. The internet is only used to download libraries and for Git.

Which phones work?

Android 7.0 or newer with a 64-bit ARM processor, which covers most phones made in the last several years.
